# Evidence records

**English** | [简体中文](#验收记录)

These files record acceptance runs on real computers. Before the repository was made public, on 2026-11-26, they were edited to remove personal and internal details:

- the computers' Tailnet addresses became `100.80.10.11` and `100.80.20.12`;
- home directories became `C:/Users/you` and `/home/you`;
- the Linux computer's name and SSH alias became `Linux` and `linux-host`, so the example service is now `linux-todo-api`;
- gateway and model names that were not public became generic descriptions.

So a SHA-256 recorded in a file here, or in the docs and examples that cite these runs, refers to the original run's files, not to the edited copies in this repository. `ssh-todo.png` was retaken from the same example code on one computer.

## 验收记录

这些文件记录了在真实电脑上跑的验收。2026-11-26 仓库公开前，为去掉个人和内部信息改过：

- 电脑的 Tailnet 地址改成 `100.80.10.11` 和 `100.80.20.12`；
- 用户目录改成 `C:/Users/you` 和 `/home/you`；
- Linux 电脑的名字和 SSH 别名改成 `Linux` 和 `linux-host`，示例服务名随之改成 `linux-todo-api`；
- 不公开的网关名和模型名改成了泛称。

所以这里的文件、以及引用这些验收的文档和示例里记下的 SHA-256，对应的是当时运行的原始文件，不是本仓库里改过的副本。`ssh-todo.png` 是在一台电脑上用同一份示例代码重拍的。
