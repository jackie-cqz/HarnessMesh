「只用 MCP」做成一种安装方式：代码不拆，一条命令装好，这台电脑只主动连出去、不开端口

2026-11-25 定的方向：不拆代码、只出不进、权限仍在面板回答。核查发现 MCP 服务只是本机 daemon 的前端，所以「只装 MCP」的实际含义是：daemon 当连接器用，不登记本机 Agent，不对外开端口。

1 条命令hmesh setup，选「只用 MCP」或「全部」
0 个对外端口只用 MCP 时，daemon 只监听本机，只主动连配对的电脑
不需要 Node.js 和 ACP Agent只用 MCP 的电脑只装 hmesh 一个程序
以后切到「全部」不用重新配对证书一开始就带上 Tailnet 地址

两种安装方式

只用 MCP：让我的 Claude Code、Codex 调用别的电脑上的 Agent
全部：同时把本机 Agent 分享给配对的电脑
只用 MCP全部
适合谁平时在终端用 Claude Code、Codex，想让它们调用别的电脑上的 Agent这台电脑上的 Agent 也要给别的电脑用
需要装hmesh 一个程序，Tailscale再加上你自己装好的 ACP Agent
daemon 监听只有本机 127.0.0.1本机 + Tailnet IP
配对只能由这台发起：粘贴对方的配对码两个方向都行
别的电脑能调用这台的 Agent 吗不能（这台没有登记 Agent，也连不进来）能
对方 Agent 的权限请求都在这台电脑的面板或「工作待办」里回答（和现在一样）
开机自动运行 daemonMac、Windows 装成登录项（已有 hmesh startup install）；Linux 由 MCP 在需要时自动拉起

需要你定的事

1. 安装入口用 Rust 子命令 hmesh setup（推荐）好处：预编译包里直接能用，只用 MCP 的电脑不用装 Node.js。另一个选择是在 start-tailnet.mjs 上加 --mcp-only，改动更小，但用户得先装 Node.js 并且要有源码。
2. 接入 Claude Code、Codex 前逐个询问（推荐）改的是你自己的配置文件，问一句更稳；带 --connect 参数就不问。另外两个选择：默认直接写（快，但会悄悄改配置），或者只打印命令让你自己执行（最保守，但多一步）。
3. 「全部」也问要不要接入本机的 Claude Code、Codex（推荐）这样本机 Agent 和你自己用的 Agent 都能调用别的电脑；不接入也不影响别的电脑调用本机。

风险和应对

从「只用 MCP」切到「全部」时，证书不对就得重新配对应对：「只用 MCP」时生成证书就写进 Tailnet IP，切换时只是打开端口。Tailscale 换了 IP 时，两种方式本来就都要重新配对（现在也是这样）。
对方不知道这台电脑不接受连接，会反复探测、显示为不可达应对：对方自己是 Tailnet 节点、却看到这台电脑的地址是本机回环地址时，就当作「只调用」，不探测、不显示红色状态（同一台电脑上的演示节点本来就用回环地址，不受影响）。不用改配对协议，所以老版本的电脑照样能和它配对。
MCP 自动拉起 daemon，可能和登录自启的那个同时启动应对：daemon 本来就有目录锁，第二个会直接退出（已有测试覆盖），MCP 只等 daemon.json 出现。
只用 MCP 的人仍然要打开面板配对、回答权限这是这次定的（权限留在面板）。以后可以评估在 Claude Code 里直接问（MCP elicitation），本方案不包含。

怎么验证

  • 双节点端到端测试：A 用「只出不进」，粘贴 B 的配对码完成配对；A 通过 MCP 在 B 的 Agent 上开会话、拿回答复；B 主动连 A 失败；B 的面板显示 A 为「只调用」。
  • hmesh setup 测试：在临时 HOME 下分别走两种方式，检查节点配置、登录项计划和写入的 Claude Code、Codex 配置；用假的 claude 命令确认只在同意后执行。
  • 切换测试：「只用 MCP」配对后再 setup --full，原配对仍可用，对方现在能调用本机 Agent。
  • MCP 自动拉起：daemon 没在跑时调用 mesh_list_agents 成功；两个 MCP 同时启动只起一个 daemon。
  • 面板冒烟：只用 MCP 时的配对弹窗、Agents 页、对方「配对节点」页，深浅色和窄屏截图。

依据

  • MCP 的六个工具全部转发给本机 daemon：crates/hmesh-mcp/src/lib.rs:247（local_client），以及 /local/sessions、/local/mesh/agents 等调用。
  • hmesh-mcp 依赖 hmesh-daemon，单独的 hmesh-mcp 是 9.1 MB，hmesh 是 23.5 MB（release，macOS arm64），拆编译省不了多少。
  • 网络方式目前只有两种：crates/hmesh-core/src/lib.rs:702。证书只在 Tailscale 模式写入 Tailnet IP：crates/hmesh-security/src/lib.rs:99。
  • 非本机连接只在 Tailscale 模式允许：crates/hmesh-transport/src/lib.rs:129。
  • 登录自启只支持 Mac 和 Windows：crates/hmesh-cli/src/startup.rs（Linux 分支返回不支持）。
  • 配对完成只需要发起方主动连对方（PR #12 的后台确认），所以「只出不进」的电脑也能配对。
